Overview

No server This app runs Python in your browser using Pyodide, so it can be hosted on GitHub Pages.

You write Python in the editor to define experimentdesign, then the app simulates pipetting + an 8-channel spectral sensor response and displays a table of results.

Because everything runs locally in your browser, reloading the page resets the session and clears stored results.

Quickstart

  1. Open the app and wait until the status says “Ready”.
  2. Edit the Python in the textbox to create experimentdesign.
  3. Click Run.
  4. Review the “Results” table and download CSV if needed.

Minimal example

# One experiment
experimentdesign = [{"R": 298, "Y": 1, "B": 1, "well": "A1"}]
print("Designed", len(experimentdesign), "experiments")

Experiment design input

Your script must define a variable named experimentdesign as a list of dictionaries.

Required keys per experiment

Each dictionary should contain: R, Y, B (volumes in µL). You may optionally include well.

Constraints

  • Each of R/Y/B must be between 1 and 300 µL.
  • Total volume (R+Y+B) must be ≤ 300 µL.

Auto-assigned wells

If you omit well, the app assigns wells sequentially (A1, A2, …) in an 8×12 plate.

The code in the textbox is executed as Python in the browser. Only run scripts you trust.

DOE example

The “Load DOE” button inserts a sample design that sweeps volumes and keeps total volume at 300 µL. 

# DOE: 24 mixtures
experimentdesign = []
for i in range(24):
    R = 10 + (i % 6) * 20
    Y = 10 + (i // 6) * 4 * 30
    B = 300 - R - Y
    if B < 1:
        continue
    experimentdesign.append({"R": R, "Y": Y, "B": B})
print("Designed", len(experimentdesign), "experiments")

Simulation model (backend)

The backend is a Python module (loaded by the page) that defines VirtualColorMixingLab.

What is simulated?

  • Pipetting error: each target volume is perturbed by a random error model.
  • Optical attenuation: each channel count is computed from baseline intensity and dye absorption using an exponential Beer–Lambert style relationship.
  • Well bias + random noise: systematic per-well factor plus random multiplicative noise.

Why “native” and “legacy” channels?

Internally the model uses “native” channels (e.g., ch415, ch445, …) but returns “legacy” channel names (ch410, ch440, …) to match the UI table.

Results columns

Each row corresponds to one experiment and includes volumes, a well position, and 8 sensor channels: ch410, ch440, ch470, ch510, ch550, ch583, ch620, ch670.

Mixture swatch

The “Mix” swatch is a simple RGB weighted blend of three fixed primary colors (red/yellow/blue) based on volumes.

Intensity

“Intensity” is computed as the sum of the 8 channel counts (a quick brightness proxy).

CSV export

Clicking “Download CSV” exports the current session’s stored results log as CSV.

If you reload the page, the in-browser Python session resets and previous results are lost.

Troubleshooting

Stuck on “Initializing Pyodide…”

  • First load can be slow (Pyodide runtime + packages).
  • Try a hard refresh and check your browser console for network errors.

“Execution error: … experimentdesign not defined”

Your script must set experimentdesign = [...] at the top level (not inside a function).

Volumes rejected

Ensure each of R/Y/B is within 1..300 and R+Y+B ≤ 300.
